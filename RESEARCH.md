## Unverified mechanics / trainer assumptions

Code-generation distribution, repeat rules, target refresh timing, mistake penalties, actual count and length of stages, timer start semantics and meaning of the progress bar remain unknown. The trainer uses uniform random symbols with repeats, six symbols and one code by default. It leaves the target visible, advances immediately on correct input and retains position on an error. All additional code lengths, code counts and reset-on-error settings are explicit practice options. It does not reproduce a hidden or unsupported official stage.

If an official public practice link or clearer gameplay video becomes available, compare those mechanics before relying on this as a faithful simulation.
